# Proposal

## Why

介面在 3D 森林之上疊了暗角、標語、頁尾、木牌、葉片與大量風格化文案，同一條規則在首頁出現三次，干擾遊玩也讓畫面顯得雜亂。樣式層沒有共用元件與設計 token：7 套按鈕各自實作、`style.css` 有 87 種寫死色碼，`main.ts` 以一段 `innerHTML` 字串組出整個介面，外觀與行為難以保持一致。低畫質切換在只支援桌機與筆電後已無明確需要。

## What Changes

- **BREAKING**：移除低畫質切換（頂部 `◈` 按鈕與降低背景、陰影、粒子的模式），不提供自動降級。
- 移除裝飾性介面：暗角、頁尾、標語、品牌圖示、首頁與訊息頁的英文 eyebrow 與裝飾副標、攝影機卡 `LOCAL` 標籤、排行榜木牌外框與葉片裝飾、前三名徽章。
- 遊玩中 HUD 只顯示分數與剩餘時間；最高連切移到結算顯示。攝影機卡只在未偵測到手時顯示一行提示。每顆水果不再跳出 `+10` 飄字，連切與炸彈保留飄字。
- 首頁規則收斂為一行（伸出食指切水果 · 30 秒 · 炸彈 −50），排行入口改名為「排行榜」。
- 排行榜文案改為精確提示：可留名時顯示預估名次；未達標只顯示「需超過 N 分」（取消追平與超越兩種差距）；載入、送出、限流、衝突、未啟用各一句說明。移除「森林信使」等風格化文案；名字錯誤收斂為一則訊息。
- 不支援裝置的說明改為簡短的精確文字。
- 建立設計 token 與共用 Button、Surface、Status 元件，所有按鈕以同一元件的 variant 與 size 呈現，介面改由元件組裝。

保留：試切、首頁排行入口、手機不支援提示、靜音、暫停、排行榜所有狀態判斷與提交行為、空白名字預設值「不知名的勇者」。

## Capabilities

### New Capabilities

無。

### Modified Capabilities

- `forest-presentation`：移除低畫質需求（保留啟動失敗的明確錯誤）；切割回饋取消一般水果飄字；不支援裝置說明改為精確文字；新增精簡且一致的介面需求。
- `historical-leaderboard`：首頁入口名稱與畫質設定敘述；未達標只顯示入榜門檻；森林風格對白改為精確狀態提示；名字錯誤訊息合併；排行榜視覺由木牌、葉片、前三名徽章改為簡潔列表並標示本局。

`arcade-session` 不變：其規格只要求結算顯示最大連切，未規定遊玩中顯示。

## Impact

- 前端：`src/main.ts`（改以元件組裝、`mode` 型別化）、新增共用 DOM 與元件模組、`src/ui/leaderboard.ts`、`src/leaderboard/rules.ts`（文案與錯誤訊息）、`src/scene/forest.ts`（移除低畫質分支）、`src/style.css`（token 與元件樣式，移除裝飾）。
- 測試：`tests/leaderboard-rules.test.ts`、`tests/e2e/game.spec.ts`、`tests/e2e/leaderboard.spec.ts` 中依賴舊文案、低畫質按鈕與 `.top1` 的斷言需更新。
- 後端：無影響。預設名字、名字驗證規則、API 與資料庫不變。
- 文件：README 中低畫質、`歷史排行 TOP 10` 與規則表述需同步；README 整體精簡另以一般 commit 處理，不在本 change。
